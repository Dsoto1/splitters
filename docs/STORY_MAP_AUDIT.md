# Story map audit (2026-11-25)

The owner's direction (2026-11-25; docs/STORY_CAMPAIGN.md, "Map pass and clusters"): use the maps we have for the story, in clusters of 3 by period or theme, the 3rd a boss or challenge map; move the rest to Community maps or another named section; convergence maps (all new) join two linked clusters with a time-fault line across one half; the big map pass is the one that builds the story out.

This is a plan to read, not a decision. Nothing here changes a map. The owner's answers (§6) come first.

**In short:** 67 listed maps (68 files minus 20 retired; Training Range is unlisted and stays out). **36 go into 12 clusters** with no new map needed to fill any cluster. **31 move out** to three named sections and Community. New maps: **1 finale** (Emperor Kronax) and **the convergence maps** (8 candidates; the owner picks how many).

How to read the work column:
- **Polish**: the map is finished and fits. Lighting, props, its story challenges and boss setup only.
- **Refresh**: layout kept, a new look with today's kits (painting, generated environment, set pieces).
- **Rework**: real layout changes or a rebuild (mostly already queued).
- **Reimagine**: a game or film homage made original and themed to its cluster. Already decided for the 21 game homages (owner, 2026-11-23), so the story gives that work a theme rather than adding it.

## 4. Convergence candidates

All new maps. Each joins two clusters the timeline links, one theme per half, with the fault line splitting one half (owner's words: "a celestial fault line of time and space"). Candidates only; the owner picks.

| Pair | Idea | Reuses |
|---|---|---|
| Mesoamerica × Desert Kingdoms | two pyramids, two suns | Jungle Ruins (06) and Desert City (09) packs, ancient tiles, generated jungle and desert ground, hypogeum and sunken arena set pieces, kit domes |
| Medieval × Frozen | knights' harbour town meets a Viking fjord | Medieval Village (10), Snow Outpost (12), Coastal Harbor (11) quays, courtyard gate and fort set pieces |
| Wild West × The Machines | frontier railhead against the machine foundry | Frontier Dust (02), Industrial Factory (13), Dustwater's train and train kit, loading dock and catwalk set pieces |
| WW2 × Suburbia | the 1944 bunkers against the 1950s atomic test town | Military Compound (01), Suburban Chaos (08), trench, casemate and bunker cluster set pieces |
| Victorian Gothic × Medieval | the manor built over a ruined keep | Gothic Estate (05), Medieval Village (10), tunnels set piece, Hollowmere's traps (logic) |
| Lockdown × Future City | Vesk's prison today and his cryo vault in 2032 | Urban & Civilian (14), Neon Megacity (07), Cormorant Isle's cell kit, server vault and power core set pieces |
| Future City × Space | a neon city under a space elevator | Neon Megacity (07), Orbital Station (04), skybridge and stair tower set pieces, low gravity, force fields |
| Desert Kingdoms × Space | a pyramid as an alien landing pad | Desert City (09), Orbital Station (04), Sunstone Crag's tomb ideas, landing set piece |

The fault line itself is one new MapMaker piece that every convergence map uses (a seam: the ground theme, sky and light change across it, with a steady glowing crack), not code for one map (CLAUDE.md, Maps). It must pass the flicker check: a steady glow, no crackle or flashing (CLAUDE.md, Accessibility). Force fields, lit signs, portals, painting and backdrops already exist to build it from.

The finale (Emperor Kronax, "the end of the line") is where every fault meets: new, and not a pair.
